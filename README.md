## Media gallery

A simple static website for displaying images and videos. Plain HTML/CSS/JS.

The media items fill the screen and stay centered in the same spot (on top of each other), while description cards scroll over the image. Which item is shown depends on which description card is currently visible.

Add media files into `assets/images` or `assets/videos`, video thumbnails to `assets/thumbnails`, and metadata to `js/mediaData.js`.
